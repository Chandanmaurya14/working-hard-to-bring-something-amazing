# Coming Soon Page

This project is a simple "Coming Soon" webpage created using HTML and CSS.

## Project Structure

```
/A:/webdevpro/CSS/06_comming_soon/
│
├── index.html
├── styles.css
└── readme.md
```

## HTML

The `index.html` file contains the structure of the webpage. It includes a header, a main section with a countdown timer, and a footer.

## CSS

The `styles.css` file contains the styling for the webpage. It includes styles for the layout, typography, and responsiveness.

## How to Use

1. Clone the repository to your local machine.
2. Open `index.html` in your web browser to view the "Coming Soon" page.

## Features

- Responsive design
- Countdown timer
- Simple and clean layout
